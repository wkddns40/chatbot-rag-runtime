# 검증 기록 · 2026-09-27

- Windows Docker Desktop Linux 엔진에서 Compose 빌드 및 app/PostgreSQL/Qdrant 기동 확인.
- 통합 테스트 7개: 인증·소유권, 반입 승인·ACL, 첨부 격리, 출처·이력 저장, 업로드 검증, SSE 및 중단 처리, 피드백·UI 응답.
- Chromium: 토큰 연결, 합성 문서 반입·승인, RAG 응답·출처 렌더링, 390/768/1440px 가로 넘침 검사.
- 공개 파일 검사: 설치 시 생성한 키, 개인키 패턴, 사설 IP 리터럴, 환경파일 포함 여부 검사 및 수동 확인.
- 원본 사내 저장소·이력·데이터·접속 설정을 복사하지 않음. 운영 서버에 접속하지 않음.
- GitHub Actions의 깨끗한 Linux 환경에서도 Compose 기동 및 통합 테스트 성공.
- Python 의존성 `pip-audit` 검사에서 알려진 취약점 없음. 초기 기본 이미지의 pip는 26.2.1로 갱신.

실제 GLM/SGLang GPU 추론과 의미 임베딩 모델은 실행하지 않았습니다. API 호환 스트리밍은 로컬 테스트 서버로 검증했습니다.
CPU 모드는 합성 문서와 해시 임베딩으로 데이터 경로를 검증하며 모델 품질을 재현하지 않습니다.
이 기록은 보안 인증이나 인터넷 서비스 운영 적합성 보증이 아닙니다.
